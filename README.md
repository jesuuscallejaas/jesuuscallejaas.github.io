# Portfolio · Jesús Callejas Soto

Portfolio profesional publicado en **https://jesuuscallejaas.github.io/**.

Sitio estático (HTML, CSS y JavaScript sin dependencias) alojado en GitHub Pages.

## Estructura

```
index.html                       Contenido de la página
styles.css                       Estilos (tema claro/oscuro, responsive)
script.js                        Menú móvil, tema, animaciones y copiar email
documents/CV_Jesus_Callejas_Soto.pdf   CV descargable
images/mi-foto.jpeg              Foto de perfil
images/projects/gramola-poster.svg     Portada del vídeo de Gramola
videos/demo_gramola.mp4          Demo de Gramola Virtual
```

## Actualizar el CV

Sustituye `documents/CV_Jesus_Callejas_Soto.pdf` manteniendo el mismo nombre:
todos los botones "Descargar CV" apuntan a ese archivo.

## Probar en local

Abre `index.html` en el navegador o sirve la carpeta:

```
python -m http.server 8000
```
